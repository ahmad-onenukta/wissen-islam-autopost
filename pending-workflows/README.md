# Workflows einmalig aktivieren

Der GitHub-Connector darf keine Workflow-Dateien schreiben (fehlender workflow-Scope).
Einmalig per Hand: Datei oeffnen -> Edit (Stift) -> Dateiname oben auf `.github/workflows/engage.yml` bzw. `.github/workflows/produce.yml` aendern -> Commit changes.
Danach diesen Ordner loeschen.
